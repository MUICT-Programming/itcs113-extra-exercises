# K: Kun Ya WiFi Password

You're an engineer tasked with assisting an elderly woman in setting her WiFi router password. However, the password must be between 4 and 6 characters long (So she can remember). Concerned about the need to come to her house, you've decided to write a C program that she can run to verify if her password complies with the length requirement. Kindly provide the program.

Password should be an integer and will not be leading by 0.

## Input Format

An integer `n` where `0 < n <= 10^6`

## Constraints

-

## Output Format

An integer of number of digits and result whether it's pass or not.

## Sample Input 0

```
239402
```

## Sample Output 0

```
6, Pass
```

## Sample Input 1

```
1
```

## Sample Output 1

```
1, Not Pass
```
