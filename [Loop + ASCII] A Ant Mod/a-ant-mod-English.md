# A: A Ant mod

You are a nursery teacher. You want to print out A-Z poster but unfortunately you are too lazy! So you decided to turn on your laptop to write a C program. Then you got an idea that you should print Uppercase and lowercase together for each alphabet.

If user type 1 it should print

```
Aa
```

If user type 26 it should print

```
Aa-Bb-Cc-Dd-Ee-Ff-Gg-Hh-Ii-Jj-Kk-Ll-Mm-Nn-Oo-Pp-Qq-Rr-Ss-Tt-Uu-Vv-Ww-Xx-Yy-Zz
```

> **Hint:** In ASCII, `a == 97` and `A == 65`

## Input Format

An integer `n` where `0 < n <= 26`

## Constraints

-

## Output Format

```
Aa-...
```

## Sample Input 0

```
1
```

## Sample Output 0

```
Aa
```

### Explanation 0

Since it is 1, it will print only 1 term of alphabet which is `Aa`.

## Sample Input 1

```
26
```

## Sample Output 1

```
Aa-Bb-Cc-Dd-Ee-Ff-Gg-Hh-Ii-Jj-Kk-Ll-Mm-Nn-Oo-Pp-Qq-Rr-Ss-Tt-Uu-Vv-Ww-Xx-Yy-Zz
```
