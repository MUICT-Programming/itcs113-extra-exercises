# S: Season Change

You as a Meteorology expert, have been challenged by your friend, Poon, to answer the season of each month and day provided.

Your knowledge are:
1. It's Hot season if and only if the date is between first (1st) of March and May 15th.
2. It's Rainy season if and only if the date is between May 16th and end (31st) of October.
3. It's Cold season if and only if the date is between first (1st) of November and end (assuming 28) of February.

and print in the format of `"Date: day/month season"`

## Input Format

`N` - number contains month and date e.g., `1226` = December 26

## Constraints

-

## Output Format

```
Date: day/month season
```

## Sample Input 0

```
1226
```

## Sample Output 0

```
Date: 26/12 Cold
```
