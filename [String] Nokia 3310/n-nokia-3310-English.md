Your grandpa John used Nokia 3310 for more than 20 years.

![Nokia 3310](https://upload.wikimedia.org/wikipedia/commons/thumb/e/e6/Nokia_3310_Blue_R7309170_%28retouch%29.jpg/640px-Nokia_3310_Blue_R7309170_%28retouch%29.jpg)

*Figure 1: Nokia 3310*
*(source: https://th.wikipedia.org/wiki/โนเกีย_3310)*

As a good lahn pu, you bought John a new smartphone iPhone 16 Pro Max with 2TB Storage Dessert Titanium. Unfortunately, your John cannot use the present way input interface which is keyboard. He misses the old numpad of Nokia 3310.

![iOS18 Keyboard Interface](https://s3.amazonaws.com/hr-assets/0/1727234579-c85d6c1803-TypeDefault.png)

*Figure 2: iOS18 Keyboard Interface*

That's pretty sad 😔.

By the way, as a top CS student in ICT Mahidol, you come up with a brilliant idea. You are going to make a software to replace iOS keyboard.

These are the features of your software:
1. After receiving data from the interface, you will get something like `4442228`
2. Then your program will translate the numbers into words that is `4442228` ---> `ICT`

![Nokia 3310 Numpad closed-up](https://s3.amazonaws.com/hr-assets/0/1727237773-02668457c1-Screenshot2024-09-25at11.15.22AM.png)

*Figure 3: Nokia 3310 Numpad closed-up*
*(source: https://th.wikipedia.org/wiki/โนเกีย_3310)*

Let's Implement it!

## Input Format

`N` - Sequence of numbers which is input from the numpad

## Constraints

`N` will be composed of digits: `2, 3, 4, 5, 6, 7, 8, and 9`

## Output Format

`W` - converted word (uppercase letters)

## Sample Input 0

```
4442228
```

## Sample Output 0

```
ICT
```

## Sample Input 1

```
8887776653444
```

## Sample Output 1

```
VRNJDI
```
